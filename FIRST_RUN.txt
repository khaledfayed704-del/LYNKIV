LYNIKV TOOL Qr — تشغيل على Termux (أندرويد)
==============================================

1) افتح Termux ثم نفّذ:
     pkg update && pkg install -y python
     pip install requests

2) انتقل إلى مجلد الحزمة وفكّها:
     cd ~/storage/downloads
     unzip -o LYNIKV-TOOL-Qr-termux.zip
     cd lynikv

3) شغّل:
     chmod +x run.sh
     ./run.sh

4) افتح المتصفح على:  http://127.0.0.1:8770

5) من تبويب "المفتاح" أدخل مفتاح الذكاء الاصطناعي واحفظه.

حلّ QuREO على أندرويد:
-----------------------
  لا يوجد Playwright للأندرويد، فتعمل الأداة تلقائياً عبر HTTP
  (qureo.transport=auto يختار HttpTransport حين يغيب المتصفح).
  من تبويب QuREO داخل اللوحة أدخل:
     الكورس + رقم الطالب + كلمة المرور
  ثم اضغط تشغيل. ستُسجَّل الدخول عبر:
     POST https://me-portal.qureo.education/oauth2/password-login
  وتفتح جلسة موقع التعلّم بلا نافذة متصفح.
  إن رفضت البوابة فتأكد من الرقم/الكلمة؛ وإن لم تصل الجلسة
  إلى me-tp فاكتب الخطأ كما هو وسيرسله لي.

ما يشتغل وما لا يشتغل:
-----------------------
  [+] اللوحة كاملة (10 تبويبات، 22 أداة)
  [+] الذكاء الاصطناعي (7 مزوّدات)
  [+] حلّ QuREO عبر HTTP
  [-] أدوات المتصفح (تعيد رسالة واضحة بدل الانهيار)
  [-] تشغيل المتصفح نفسه

أوامر مفيدة:
     ./run.sh --cli      الطرفية الكاملة
     ./run.sh --status   حالة الخادم
     ./run.sh --stop     إيقاف الخادم
